# Budget Manager
Account management system allowing monitoring expenses and incomes.

## Tech Stack
- Java
- React + TypeScript
- PostgreSQL
- Docker

## How to run

1. Clone the repo
```bash
git clone https://github.com/mateuszmnnm03/budget-manager
```
2. Build and run the environment for development
```bash
docker compose up -d --build
```
